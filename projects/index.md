# Project

The course project provides hands-on experience designing and implementing a database-backed application.
Students will work individually or in small teams to build a system that demonstrates mastery of the concepts covered in lectures.

Projects should use PostgreSQL, DuckDB, or both, and involve non-trivial schema design, query optimization, and performance analysis.

## Milestones

| Milestone | Due Date | Points | Description |
|-----------|----------|--------|-------------|
| Proposal | Sep 25, 11:59 PM | 50 | Problem statement and database design |
| Checkpoint | Oct 23, 11:59 PM | 75 | Working prototype with schema and queries |
| Final Report | Dec 2, 11:59 PM | 125 | Complete report and presentation |

More details on each milestone will be released as the semester progresses.
