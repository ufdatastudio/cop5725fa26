- [HiPerGator for COP 5725](hipergator-getting-started). Account request, storage under `/blue/cop5725`, interactive and batch jobs on the class allocation, uv on the cluster
- [Research Computing Orientation](research-computing-orientation.pdf). UF Research Computing's slides introducing HiPerGator
- [Running Your Own PostgreSQL Server on HiPerGator](hipergator-postgres-apptainer). Your own server in an Apptainer container on the class allocation, with scripts to create, start, and destroy it
- [PostgreSQL toolkit for HiPerGator](hipergator-postgres/). The scripts themselves, readable in the browser and downloadable with `curl` or `wget`
